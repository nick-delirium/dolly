#### Decisions

- The `done` guard lives at entry points: CLI `guardDone` (uses `notAHuman()`) and the MCP write gate. It is not in `setStatus`. Side effect: `! dolly status x done` typed inside Claude Code is refused (h2snm7k7 step 0001).
- A task never closes automatically on merge. Commit evidence is shown in review, and the human decides there.
- `log.jsonl` holds task.md state only. Prose stays in markdown, so PR diffs stay readable.
- There is no `dolly render` command. The auto-migration's detect heals task.md, which keeps the surface at 26 commands.
- `show` stays as an alias of `context`. `related <file>` became `why <file...>`.
